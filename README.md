# Печать сумрака / GameDead

Кооперативное фэнтезийное выживание для 2–4 игроков. Целевой забег — около 30 минут, рывок — Shift.

Первый этап — сервер аккаунтов. Графический клиент, арена и комнаты появятся следующими этапами.

## Требования

- JDK 21.
- PostgreSQL и подготовленная база `gamedead`, пользователь `gamedead_app`, схема `game`.
- Интернет для первой загрузки Gradle и зависимостей. Gradle устанавливает Wrapper.
- IntelliJ IDEA необязательна: проект можно собрать из PowerShell.

## Сборка

Открой корневую папку проекта в IntelliJ IDEA; выбери JDK 21 для проекта и Gradle JVM, используй Gradle Wrapper.

В PowerShell из папки проекта:

```powershell
$env:GRADLE_USER_HOME = Join-Path (Get-Location) '.gradle-user-home'
.\gradlew.bat build
```

Эта команда не подключается к PostgreSQL. Интеграционные проверки запускаются отдельно.

## Запуск

```powershell
.\scripts\start-server.ps1
```

Скрипт запросит пароль скрыто и запустит сервер на `http://127.0.0.1:8080`. При первом запуске Flyway создаст таблицы в существующей схеме `game`. Введённый пароль действует только в процессе запуска; скрипт восстанавливает прежние переменные при завершении.

Если Windows PowerShell сообщает, что запуск скриптов запрещён, запусти этот же файл с разрешением только для нового процесса:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-server.ps1
```

Постоянные настройки политики выполнения при этом не меняются.

Сервер предоставляет JSON API; браузерного сайта и игрового окна на этом этапе нет. HTTP предназначен для локальной разработки. Перед внешним доступом нужен HTTPS; привязка к 127.0.0.1 по умолчанию ограничивает доступ этим компьютером.

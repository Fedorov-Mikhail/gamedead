# Печать сумрака / GameDead

Кооперативное фэнтезийное выживание для 2–4 игроков. Целевой забег — около 30 минут, рывок — Shift.

Реализованы аккаунты, настольный клиент libGDX, комнаты на 2–4 игроков, общий опыт, шесть улучшений и история забегов. Добавлены волны на 30 минут, три обычных типа врагов, крупный босс с рывком и выбор сложности. Победа требует уничтожить босса; правила рассчитывает сервер. Новые классы пока спроектированы. Подробности: [полный забег и классы](docs/full-run.md).

## Требования

- JDK 21.
- PostgreSQL и подготовленная база `gamedead`, пользователь `gamedead_app`, схема `game`.
- Интернет для первой загрузки Gradle и зависимостей. Gradle устанавливает Wrapper.
- IntelliJ IDEA необязательна: проект можно собрать из PowerShell.

## Сборка

Открой корневую папку проекта в IntelliJ IDEA; выбери JDK 21 для проекта и Gradle JVM, используй Gradle Wrapper.

В PowerShell из папки проекта:

```powershell
$env:GRADLE_USER_HOME = Join-Path (Get-Location) '.gradle-user-home'
.\gradlew.bat build
```

Эта команда не подключается к PostgreSQL. Интеграционные проверки запускаются отдельно.

## Запуск

```powershell
.\scripts\start-server.ps1
```

Скрипт запросит пароль скрыто и запустит сервер на `http://127.0.0.1:8080`. При первом запуске Flyway создаст таблицы в существующей схеме `game`. Введённый пароль действует только в процессе запуска; скрипт восстанавливает прежние переменные при завершении.

Если Windows PowerShell сообщает, что запуск скриптов запрещён, запусти этот же файл с разрешением только для нового процесса:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-server.ps1
```

Постоянные настройки политики выполнения при этом не меняются.

Сервер предоставляет JSON API. Для игрового окна открой второе окно PowerShell и запусти:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-client.ps1
```

Если сервер использует порт 8081, добавь `-ServerUrl http://127.0.0.1:8081`.

Подробный запуск, сборка готового комплекта и проверки: [настольный клиент](docs/desktop-client.md).

Для проверки совместной игры запусти два клиента под разными аккаунтами. В профиле нажми «Играть с друзьями»: один игрок создаёт комнату, второй вводит её код. Когда все нажмут «Готов», владелец сможет начать забег. Подробности: [комнаты и арена](docs/rooms-and-arena.md), [правила боя](docs/combat.md), [прокачка, награды и история](docs/progression.md).

HTTP предназначен для локальной разработки. Перед внешним доступом нужен HTTPS; привязка к 127.0.0.1 по умолчанию ограничивает доступ этим компьютером.

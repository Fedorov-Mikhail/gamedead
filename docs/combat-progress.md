# Первый бой: ход реализации

Основа: [next-combat.md](next-combat.md), пользователь разрешил начать реализацию 2026-10-16.

Работа в ветке `codex/combat`, в текущей папке проекта, чтобы пользователь запускал обновлённую игру прежними скриптами. Исходные загрузки `visual` сохраняются. Новые зависимости, миграции, размещение сервера и автоматическая отправка в GitHub в этот этап не входят.

Порядок: тесты и расчёт боя → протокол и сервер → клиент и графика → проверки и ревью.

Решения: версия игрового протокола 2; первый `stop` прерывает бой с результатом ABORTED, следующий возвращает отряд в лобби. Победа, поражение и прерывание остаются в снимках до возврата в комнату. Длительность по умолчанию 240 секунд, сервер допускает настройку до 1800 секунд. Результат и опыт аккаунта пока не записываются в БД.

Реализованы: расчёт боя, протокол 2, серверный жизненный цикл и клиентское управление/отрисовка. Новые правила прошли RED→GREEN: стрельба, здоровье, спасение, результаты, версия протокола, одинаковый tick при прерывании, немедленный снимок при выходе, спасение одного союзника за раз. Сетевая проверка использует настоящий Spring Security/MVC/WebSocket с заменой только границы сохранения аккаунтов.

Графическая проверка проходит при 1280×720 и 960×640: мышь и атака, WASD, Shift, победа, поражение, прерывание, повторный старт и выход. Снимки арены и результата просмотрены.

Независимое ревью нашло ошибку дискретного определения попаданий. Два сценария воспроизведены тестами; алгоритм заменён точным выбором первого пересечения отрезка с врагом или стеной, включая скруглённые углы стен. Повторное ревью этих исправлений не нашло важных замечаний. Также обновлён тест проверки личности участника до версии протокола 2.

Итоговая команда `build :client:installDist :client:desktopCheck --rerun-tasks --offline --console=plain` завершилась успешно. Все 121 тест проходят: 20 расчёта мира, 50 сервера, 51 клиента, без пропусков. Готовый комплект клиента пересобран; графическая проверка повторно прошла после исправлений попаданий. Проверка максимального снимка с четырьмя игроками, 40 врагами и 128 снарядами подтверждает JSON round-trip и размер меньше 64 KiB.

Статус: этап реализован и проверен автоматически. Ручная проверка с настоящими аккаунтами, PostgreSQL и внешней сетью остаётся отдельной задачей. Интеграционные тесты БД не перезапускались: схема и логика сохранения аккаунтов не менялись. Изменения сохранены локально в `codex/combat`; отправка этого этапа в GitHub не выполнялась.
